# 家庭网络设备行为画像与异常检测系统（脱敏演示）

一个部署在家庭内网里的被动流量观测与异常检测系统。

采集点设在主路由——全屋流量的必经之处，终端设备侧**零安装、零配置**。采集到的流量与
DNS 日志在本机汇聚入库，按「设备 × 小时间桶」计算画像特征，再用
**设备自身历史留一基线 + 稳健统计 + 规则判据** 检出异常，最后渲染成只读网页看板。

## 演示站点

- `index.html` —— 概览：采集规模、设备构成、域名归类、每日趋势
- `devices.html` —— 设备画像：每台设备的 24 小时活动曲线、上下行总量、通信对端数、端口偏好
- `cases.html` —— 异常案例：3 个真实案例的完整证据链与可复核 SQL
- `method.html` —— 检测方法：基线口径、判据清单、可复核性说明

站点是**纯静态**的：全部图表为手写 SVG，零外部依赖（无 CDN、无外部字体、无图片、无 JS 框架），
双击 `index.html` 即可离线打开。

## 关于数据

演示数据来自一个**真实家庭网络** 17.6 天（18 个自然日）的连续全采样采集，已做脱敏处理：

- 设备一律以「设备 NN ＋ 角色类别」呈现，不含真实主机名、品牌或型号
- 不输出任何内网 IP、IPv6 地址或 MAC 地址
- 域名不输出原始 qname，只保留归类后的类别与占比
- 保留端口、协议、字节数、连接数、对端数等数值型证据

## 数据规模（本仓库构建时的取值）

- 连接明细 554 万条
- DNS 查询 239 万条，覆盖 15,987 个不同域名
- 设备身份 26 个（当前在线 19 台）
- 设备小时特征 4,378 个样本

## 技术栈

Python 3 标准库（无第三方依赖）、SQLite、NetFlow v5、softflowd、systemd。
